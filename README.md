## How I Work

I'd rather ship something that works today and refine it tomorrow than polish something that never leaves my machine. A few things I try to stick to:

- Get the API contract right before writing a single UI component
- Treat error messages as the first source of truth, not the docs
- Containers and CI/CD from day one, not bolted on at the end
- If it's not monitored, I don't fully trust that it's working
